## 格子与头像的坐标

- 选单位格 50×50，四边各 5 像素为边框，内框为格内 x、y 5–44（40×40）。原版头像的下沿多止于内框底行（第 44 行）。
- 头像在格内的位置由锚点决定：锚点取负值即头像左上角在格内的坐标（例 [−5, −5] 为 (5,5)）。头像可以越出内框，例如原生透明底剪影头像多为 46 高、锚点 [−5, 1]，向上越出内框 6 像素。
- 虫穴素材 93×65 大于格子，原尺寸放不下，需要缩小或只取一部分；现用头像为整体缩到 0.45 倍。
