## 2. 移植方式

- MSA 1123 与 MSD 200 的矩形尺寸与锚点、帧表、受击框逐项相同（只有图集位置不同）；去掉 MSA 专有空操作指令后，攻击槽与弹体以外各槽与 200 逐条相同（MSD 200 的本体槽 6–14 开头多 `op14[0,−10]`，为飞行高度的绘制偏移，本单位照加）。
- MSD 200 的状态 → 槽：10 槽 6、20 槽 7、30 / 40 槽 8、50 槽 9、70 槽 10、100–120 槽 11（140 播完移除）。MSD 槽 ← MSA 槽：0–7 同号，8 ← 9，9 ← 11，10 ← 14，11–14 ← 17–20，15–18 ← 38–41，19 / 20 ← 36 / 37，21–28 同号，29–31 ← 32–34；子层与弹体引用的槽号按同一对应改写。
- 攻击：MSA 的普攻（槽 8）与绝招（槽 10 / 12）发射的弹体 29–31 不带速度，由 `GruelingWingedInvader::shotBullet` 按目标方向（`getTargetAngle`，无目标时 30°）以 10° 间隔散开设定速度。记录中另有不瞄准的同一组弹幕：槽 9（普攻 3 发）与槽 11（绝招 3 轮共 9 发），弹体 32–34 为正前方 10 精灵像素 / tick 与 ±11.25°。MSD 原生 `WingedInvader::shotBullet` 经 `addBulletNotAim` 发射、不瞄准，本单位采用后者。
- op22 的第 2 个值在 MSD 为攻击状态覆盖（`onEventBulletShot` → `shotBullet` → `addBulletImpl`：0 为当前状态，30 / 40 / 50 以外不生成弹体）；MSA 的 1–12 全部改为 0。弹体 29（← MSA 32）末尾的 op21 改为 op5，与原生弹体同样循环，飞行距离由原生状态词限定。
- 不实施：MSA 的瞄准、`reAppear`（状态 77）、MSA 状态 70 的后仰（槽 16）与版本技能（多次射击命中击退、两档绝招）。
