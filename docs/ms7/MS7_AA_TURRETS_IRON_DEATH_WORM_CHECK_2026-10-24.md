# MS7 的 AA Turret（三种）与 Iron Death Worm 拟移植：资料核查

日期：2026-10-24（Asia/Shanghai）。性质：只读核查。游戏代码、内容、核心与两个固定运行目录未改动；未计算 SHA-256。
依据：用户提供的 MS7（DS）素材表 `F:\egg\MS7\`（2 张，Gussprint 拆图）、MSA 7.13.0 官方数据（`F:\egg\research\metal_slug_attack\`，arm64 `libAppMain.so` build-id `9acaace5…`）、MSD 1.46 原生库（`game_data/original.apk`）、原作通关影片（YouTube `9b51CE-ZLY4`，MS7 HD Remaster）与 MSA 单位展示影片（YouTube `0wBsLIYgv90`，Midian-P）。影片均在内置浏览器中静音逐帧查看，未下载。脚本与输出在 `verification/ms7_aa_worm_20261024/`。

## 1. 结论

- 两个对象都出自 MS7 任务 1（废品岛）：AA Turret 出现在关卡前段（通关影片约 72–104 秒），Iron Death Worm 为任务 1 首领（约 255–330 秒，节段式钻头蠕虫横穿画面）。
- MSA 中与 AA Turret 对应的是 **Scrap Cannon（废品岛炮台 / 廢鐵砲台 / スクラップ砲台）**：387 为修筑者（动作类 `Kouhei`，图集为沙包兵），388 为修筑出的炮台（动作类 `Turret7`，图集 `7turret_base_0/1`）。MSA 只有完好形态一种；849 Scrap Cannon MKⅡ 为同一造型的红色换色版（动作类 `Turret7MK2`），1333 MKⅢ 为另一造型。名称相近的 1740 / 1741「20000000 TURRETS」是带炮手的机枪炮台，与 MS7 无关。
- MS7 素材表中的 **Broken AA Turret (A)、(B)** 在 MSA 中没有对应单位、图集与数据，只能取用户提供的 MS7 素材表；其动作（原作中炮管上扬、向斜上方发射炮弹）也没有 MSA 依据，须另行设计。
- MSA 中与 Iron Death Worm 对应的是 1843 **IRON DEATH WORM（钢铁死亡蠕虫 / 鋼鐵死亡蠕蟲）**，2022-02-28 开放，动作类为匿名命名空间中的 `BattleAction_IronDeathWarm`（无导出符号，由 `createActionIronDeathWarm` 返回的静态对象经虚表还原）。MSA 版为斜插在地面、钻头朝前上方的据点型兵器：钻入地下后在目标附近钻出，绝招为钻入地下后从目标上方钻下。
- MSA 的 Iron Death Worm 与蜈蚣长老使用同一对地面裁切函数（绘制时只画地面以上部分），钻地、出土的结构也相近；MSD 核心 r80 为蜈蚣长老实现的地面裁切与 `elder_centipede` 行为可作基础。
- MSD 1.46 原生库没有 `Turret7`、`IronDeathWarm` 两个动作类。相关的原生类有 `BattleAction_Tnabe`（原版 ANTI AIR-CRAFT，UnitID 32，由 74 修筑，对空瞄准射击）与 `BattleAction_ScrapFort`（SCRAP TOWER，UnitID 366）。
- 受击判定（用户 2026-10-24 要求，第 6 节）：按 MSA 脚本直接移植时，钢铁死亡蠕虫在钻地、出土、绝招与地下移动的动作中都没有 op3；MSD 每次切换动作清空受击框，这些动作会全程无受击框（钻地 89 tick、出土前 84 tick、绝招入地 82 tick、地下钻击 80 tick）。MSA 在这些动作中沿用上一动作的受击框，只在绝招的地下钻击（80 tick）与损毁后的地下移动中置“不可选为目标”一类标记。

## 6. 受击判定（用户 2026-10-24 要求：不得再出现蜈蚣长老 / 侵略者之王那样因形态变化而长时间无受击判定）

- MSD 原生 `setAnimationID_SkipUpdate` 每次切换动作都清空受击框，须由新动作的 op3 重设；MSA 沿用上一动作的受击框（第 225、250 节已查明）。
- 钢铁死亡蠕虫各槽的 op3（`hit_timeline.py`，含 op11 / op12 / op36 子层）：

| 槽 | 动作 | 长度（tick） | op3 | 原样移植到 MSD 时 |
| --- | --- | --- | --- | --- |
| 6 | 待机 | 70（循环） | 第 0 tick 设 1 | 有 |
| 7 | 移动：钻入 | 89 | 无 | 全程无受击框 |
| 12 | 钻出 | 89 | 第 84 tick 设 1 | 前 84 tick 无 |
| 17 | 近距掘削 | 32 | 第 0 tick 设 1 | 有 |
| 25 | 绝招 / 损毁：钻入 | 82 | 无 | 全程无 |
| 33 | 绝招：地下钻击 | 80 | 无 | 全程无（MSA 期间另置不可选为目标一类标记） |
| 43 | 击退 | 70（循环） | 无 | 无（原版单位击退中同样无受击框） |
| 44 / 49 | 损毁后地下移动 / 爆炸 | 70（循环）/ 71 | 无 | 损毁后，不影响 |

- MSA 中实际不可受击的时段：绝招的地下钻击 33（80 tick，约 2.7 秒，+0x184 位 8 / 0x10 / 0x40 置位，三位的确切含义未查明）与损毁后的地下移动。移动的钻入与钻出（7、12）在 MSA 中沿用待机的受击框，可被攻击。
- 建议的处理原则（待用户确认）：7、12、25 开头补 op3；受击框按各 tick 地面以上可见部分的外接矩形分段设定（蜈蚣长老 R2 的 `body_bounds.py` 做法），始终不为空，最低保留地面处的钻孔部分；地下钻击 33 给钻头所在处设受击框，不采用 MSA 的不可选为目标标记；击退 43 按原版规则保持无受击框，或同样补框。移植后以 `verification/power_core_pass_20261023/audit_hitrect.py` 与 `run_audit.py` + `ana_audit.py` 检查全部状态的无受击框帧。
- AA Turret：388 的受击 12 补 op3；Broken (A)/(B) 由新脚本制作，全部存活动作开头设 op3。
