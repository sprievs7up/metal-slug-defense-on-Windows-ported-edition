## 3. 实现

### 3.1 动作类与行为

- 行为库 v12 新增 `iron_slider`（基准 394，参数 `second_form` 指定内部单位）与 `iron_slider_second_form`（基准 395）。加载器按行为写入 `native_action`，以原生 `BattleAction_IronSlider` / `_2` 的虚表构造动作对象，并把第二形态的 UnitID 写入第一形态数据行的子单位字（+0xa4，与其他召唤类单位相同）。
- `src/community_content.cpp` 的 7 个钩子按 MSA 7.13 处理原生较早版本与 MSA 的差异（注释在源码第 688 行起）：
  1. `setAnimationID` 槽号换为 MSA 槽号（第一形态 8→9；第二形态 94–97→17 / 18 / 19 / 21；主炮导弹 52→14；巨型导弹 77→25、84→23；侧炮炮弹 43→共用爆炸 0xff03 + 槽 15）；
  2. 第一形态 `createObject` 按 MSA 编号建立弹体：侧炮 50 / 56 / 105 / 111 / 117 / 124 / 130 / 136（攻击组 30，即近战组），火箭 60，主炮导弹 64，残片 72 / 73；
  3. 第二形态 `createObject` 建立巨型导弹 24（攻击组 40）；
  4. `summonUnit` 召唤状态块 +0xa0 记录的子单位（原生写死 395）；
  5. 取消较早版本的 (0,30) 绘制偏移；
  6. 火箭弹体：重新进入画面后瞄准对方最前方单位的中心；
  7. 主炮导弹命中、失效或落地时生成本单位带攻击框的爆炸动作 103。
- 火箭的索敌（用户要求与攻击一致）：目标须在攻击距离边缘以内（单位 x ±（半宽 + 字 7 = 300））；边缘以内没有目标时落向边缘处的地面，不追击更远的单位；水平飞离发射点达到投射距离（字 26 = 600）时爆炸。

### 3.4 受击后退与绝招蓝光（R2）

- 受击后退：原生 `BattleAction_IronSlider` 的状态 80 只播放槽 12，后退来自槽 12 的 op7 [−700, 0, 50, 0]（经 `BattleObject::actionMoveX`，实测初速 −14、每 tick 加 1，共 118）；`knockback_distance_multiplier` 由核心既有钩子在状态 80 缩放该速度与加速度。单位位于本方后退界限附近时（LAB 1011 中约 x 470），原生不再向后推，后退距离相应变短或为 0。
- 绝招蓝光：原生 `BattleUnit::draw` 在 `isSpAttack()`（绝招可发动）时以 `BattleEffectRenderer::drawSpAttackEffect` 在单位脚点绘制蓝光，宽高取状态字 43 / 44 的两倍；两字为 0 时取当前帧第一个矩形的尺寸。原生 394 / 395 两字为 0，而本单位主槽不画帧（部件均为 op11 子层），蓝光画成脚点处约 31×31 的小光点。新增单位字段 `special_effect_size`（数据行 +0x344 / +0x348）写入 [380, 120]：按原版大型载具（286 等为 [160, 90]，蓝光约与本体等宽、高约为本体的 0.4–0.5）由本体图像范围（宽约 800、高约 476）换算。

- 每发伤害值：第二形态远程攻击伤害（状态词 22）。基准 395 原生值 Lv1 500 / Lv10 750 / Lv20 1000 / Lv30 1250 / Lv40 1500，乘 `damage_multiplier` 16/3（向下取整）得 2666 / 4000 / 5333 / 6666 / 8000（R11；R6 为 32/3，即 5333–16000）。钩子 3 一律以远程组（参数 40）建立巨型导弹，近战、普通攻击与绝招三种状态发射的都是同一导弹、同一伤害；第二形态的 `special_damage_multiplier` [1,2] 与 `near_damage_multiplier` [3,10] 只使 STATUS 显示的绝招与近距伤害同为 16000，不影响实际伤害。
- 命中：导弹落地（或碰到敌方受击框）后生成火柱（脚本 26），其攻击框 10（描述符 [−192, −221, 381, 228]）在第 3–27 tick 打开，范围内每个敌方单位各受 1 次伤害（目标数 999，不限人数）；下落中导弹本身的攻击框 5 不另外造成伤害。实测（`runs/dmg_form2_*`，r75）每发对每个目标只扣 1 次，均在火柱第 4 tick；落点前方 +347 命中、+369 与 +457 未命中，约为攻击框的 2 倍（世界单位），即落点前后各约 360。
- 实际扣血 = 伤害值 × 目标自身的减伤（例：大杰受到 80%，8000 → 6400；R6 时为 16000 → 12800）；敌方出场时另受关卡强化影响（本节未测）。每次命中按第二参数（状态词 23 = 10，×100）扣目标击退计量 1000。
- 频率：攻击距离（状态词 7 = 300，自车身前缘起）内有敌方单位即反复发射；一轮为攻击动作 108 tick + 攻击等待 70 tick（状态词 27）= 178 tick（约 5.9 秒），实测发射时刻 354、532、710、888、1066、1244。单体约每秒 2700（R6；R5 约 1350），范围内多个目标各受同样伤害。绝招（冷却 500 tick）发射的也是同一导弹。
- 可调字段（`build_iron_sentinel_msa.py` 的 `SECOND`）：每发伤害 `damage_multiplier`（Lv40 伤害 = 1500 × 分子 / 分母，现为 [16,3] 即 8000；例：12000 为 [8,1]，20000 为 [40,3]）；间隔 `status_word_values` 的 27（及 20、34）；开始攻击的距离 7；击退力 `status_float_values` 的 23；范围为描述符攻击框 10（须改生成脚本）。
