# 模组 M6b-2：自制 EVENT 地图（2026-10-10，宿主，核心保持 r41）

按用户要求，自制地图采用猫咪大战争的局部适配方式：原生活动地图（EventMSD）的绘制、滚动、区域放大与触点保持原生，只在绘制时换入作者的图像。

## 1. 结果

- EVENT 可选 `"map": {"image": "<文件>"}`：1440×709 的 PNG/WebP，替换原生活动地图的世界地图图层；区域总览与区域放大（关卡页）均显示作者底图。
- 小关可选 `"thumbnail": "<文件>"`：128×56 的 PNG/WebP，显示在小关信息窗口（MISSION START 面板）中；未提供的小关保持原生缩略图（`preview_frame` 选择）。
- 区域坐标 `position` 为世界地图图层（1440×709）上的像素坐标，即作者底图上的像素位置（原版区域记录使用同一坐标系，例如万圣节 (1175, 300)）。M6b-1 文档中“x 0–1400、y 0–700”的写法已更正为 0–1440、0–709。
- 区域名（M6b-1）按游戏语言显示于关卡页左上角。

## 2. 原生依据与实现

- 以 LAB 头部 +0xb00 的 drawConv 记录（`verification/m6b1_20261010/diag_draw.py`）确认：世界地图图层由两个转换项组成，`0x10306ab4`（源 (0,0) 起 823×680）与 `0x10306ac4`（617×709，锚点 x −823），合成 1440×709；区域总览以约 0.6529 倍绘制于 (9.9, 71.6)，区域放大时同一图层放大。区域图标绘制于 9.9 + 0.6529·x（总览），即 `position` 为图层像素。小关缩略图为 128×56，万圣节缩略图组（区域记录 +12 = 34）的预览帧 f 使用转换项 `0x10307bde + 16·f`（第 f 行，y = 57·f）。
- `event_content.MapArt`：所选自制 EVENT 处于原生地图场景（158–160）时，写入 drawConv 替换表（LAB 头部 +0xb40，与 EVENT 浏览页、VERSUS 页共用，各自只在本身场景写入）：两个地图图层转换项换为作者底图（第二项的源矩形自 x=823 起），当前区域（app+0xc628）中带缩略图的小关，其预览帧转换项换为作者缩略图。离开地图场景时清除。作者图像以 `lab_versus.create_native_image` 建为原生纹理并按文件缓存。
- 带缩略图的小关，其预览帧固定为该小关在区域中的序号（0–4），使每个区域可有各自的缩略图。
- 核心未改；替换表与 r41 的 `draw_conv` 钩子相同（每次至多 8 项：底图 2 项、缩略图 5 项）。

## 5. 限制

- 单页地图。原生经典活动地图没有翻页；猫咪大战争的两页地图依赖其专用路由（WorldType 2，每区域一关），未用于自制 EVENT。
- 地图周围的网格背景与区域图标、小关标记沿用原生图形。
- 底图须为 1440×709；图像按最近邻采样。
