## 1. 背景

- 原生单位强化（主菜单 CUSTOMIZE → 单位）与单位商店（SHOP → UNIT）每页最多 50 件，卡片以拖动方式逐张移动，页末以 NEXT / BACK 卡翻页；强化每次只升 1 级；单位参数大多不显示。单位数量增加后，查找单位需要逐页翻找，社区中的拉美玩家已反馈此问题。Lv41–50 正式引入后（模组任务书第 10.2 节），逐级强化的操作次数会进一步增加。
- 单位数据层已经具备：`unit_catalog.py`（M1a）提供筛选、排序、名称搜索、按等级的完整数值与对比，4096 个测试单位时单次查询约 1–4 ms，LAB 选单位已在使用。尚缺购买与强化的操作接口（M0 规格第 7.4 节）和界面本身。
- 2026-10-11 用户决定：U1 优先于关卡创作工具、肉鸽常驻 EVENT 与地图 4；计划在本文件完成，实施在新对话中开始。

## 4. 技术要点

- **数据与操作接口**：`unit_catalog.py` 增加 `purchase(key)`、`upgrade(key, levels)`、`open_stage(key)`、`level_cap(key)`（当前上限与下一次提高上限的条件）等，返回 M0 规格第 7.4 节的统一结果对象（成功与否、原因代码、货币变化、操作后的条目）。操作后刷新受影响条目。
- **渲染**：采用按钮翻页后不再需要逐帧平滑滚动。卡片、进度条与文字仍建议用 GL 直接绘制已载入的纹理（原版图标图集、M1b 图标页、阵营标志、缓存的文字纹理），使翻页在一帧内完成；LAB 准备界面的 PIL 整屏合成约 48 ms（第 49 节），可用于静态面板。

### F.3 过渡（新增 `unit_motion.py`，含 `src/` 镜像；`unit_browser.py`、`unit_menu.py`）
