### 3.2 宿主 `deck_page.py`

- **选单位条**：面板仍为原生任务（图标、SELECTED 标记、按住拖放均为原生）。宿主把当前页的 UnitID 写入原生列表（其后全部清零）并把数量写入 `app+0xc014`，调用 `ClearDeckPanel`、`InitDeckPanels(0)` 重建，再把各面板横坐标改为 `-28 + 102·i`（10 格在 1280 宽画面居中）、序号改为 1000 起（原生不再画文字）；滑动范围置 0、触摸区域移出画面、位置与目标每帧保持为 0；渐暗层与原生的 3 个标签、3 个 AP 数字任务移出画面。进入场景后的首帧（闸门合拢期间）完成第一次重建。
- **翻页**：两侧箭头（原生箭头图块 2.25 倍）、键盘 ← / →、鼠标滚轮，首末页循环；右下为“页 / 总页数”（原生银色数字）。只有 1 页时不显示箭头与页码。触点按下期间不受理键盘与滚轮翻页。
- **信息行**：按下图标即选中（R1 曾加按键音效 13，R2 按用户试用结果去掉）；图标下方一行为阵营标志、名称、`LV : n / AP : n`，已编入当前编队时整行为原生的绿色（128, 200, 0）。没有选择框（R1）。进入页面与翻页后不选中任何单位、信息行为空（R4；此前默认选中该页第一个单位）；所选单位仍在当前页时切换 DECK 标签不清除。按下编队栏的单位时，选单位条跳到该单位所在页并选中它（对应原生的滚动到该单位）。
- **拖起（R1）**：按住图标移动 6 个画布像素即拖起，不需长按、不限横向位移（原生为按住 10 帧以上且横向位移不超过 39）。宿主在触点阶段执行原生开始拖动的步骤：`SetDeckDrag(uid, 面板 x + 50, 面板 y)`、把面板任务换为 `GT_DeckPanelHold`、停用滑动；拖动物按触点相对按下点的位移移动（`GT_DeckDrag`），放下、退回与编入均为原生。已编入的单位不可拖起（同原生）；只点按不移动时不拖起。原生的长按拖起仍然有效。
- **底板渐变（R1）**：按下的图标（拖动期间保持）与鼠标所在的图标为浅绿，松开或移开后 15 帧（约 0.5 秒）线性渐变回墨绿；宿主每帧把各格亮度写入核心的亮度表，由原生绘制。鼠标位置取自窗口的光标回调（`lab_runtime.py` 的 `cursor` / `cursor_enter`，光标在画面之外时为无）；触摸操作没有“划过”，只有按下与松开后的渐变。已编入的单位（红色底板）不变色。
- **EVENT 标记与编队栏数字（R2）**：重建面板时把各面板的 EVENT 标记任务移到面板的新位置（与图标的相对位置同原生；间距由 136 缩为 102 后，相邻两个标记首尾相接）。每帧检查 10 个数字任务：图块为空位（15+格）时 x 减 12（第 10 格减 18），红色数字正好盖在背景的灰色数字上；已编入的格保持原生位置。
- **SELECTED 标记（R3）**：重建面板时，在 `InitDeckPanels` 之后为每格另建一个与 EVENT 标记相同做法的原生任务（图块 0x19，所属面板写入 `+0x1b8`，槽借用标记槽第 10–19 项，`ClearDeckPanel` 一并删除）；因后于 EVENT 标记建立，画在全部面板与 EVENT 标记之上。每帧按单位是否在当前编队中把图块设为 0x19 或 -1。R5：重建面板与切换 DECK 标签时立即设定（R3 时等到当帧画面之后才设定，触点翻页后的第 1 帧没有标记）；单位刚被拖入编队的那一帧由核心让面板自己画，标记不缺帧。
- **SORT**：底栏 SORT 由宿主受理（按下期间以 `cockpit_hold` 保持原生按压外观），打开 `unit_browser.compose_panel` 的排序与筛选面板；设定独立保存在 `unit_browser.json` 的 `deck` 项（与强化、商店的设定互不影响）。面板内容变化后在关闭时重新查询并回到第 1 页；Esc、OK 或面板外点击关闭。列表为 U1 单位目录中已拥有的单位（`unit_catalog.list`，数值类排序按各单位当前等级）。
- **DECK 标签**：5 个标签由宿主以原生图块绘制（位置按原生画面逐块校准；未选中标签的 AP 数字透明度 0x7a），数字 4、5 按原版 2、3 的外框与配色规则以 6×8 字形补画（`GLYPHS`）。最右标签保持原生第 3 个标签的位置，间距由原生 198 缩为 190 以让出标题。切换：写 `app+0x88d0` 后调用 `DeckChangeInit`。
- **图层与闸门**：宿主图层画在原生画面之上。编队页的原生闸门（`ChangeNT` 17 / 18）改由本模块在图层之后推进并绘制（步骤同 `SC_ShutterClose` / `SC_ShutterOpen`），合拢完成后交还原生。原生弹窗（场景 119–122）显示期间不画信息行与选择框。面板在原生画面之后重建时，图层保持上一帧内容一帧，使图层与图标同帧更换。
- **接入**：`lab_runtime.py`（触点在单位浏览组件之前、绘制在其闸门之前、Esc、键盘、滚轮、文字输入）；`unit_browser.py` 增加 `deck` 设定；`community_content.py` 的编队核对（模组启停后的暂存与恢复）范围由 3 组改为 5 组。

### 3.3 文字缺字回退（R3，`text_render.py`，含 `src/` 镜像；对全部界面文字生效）

- 原因：各语言按 `LANGUAGE_FONTS` 选一种字体绘制（英、西、葡、法、意、德等为 Arial）。文字中含该字体没有的字符时画成未定义字形（方框）。实例：阵营加成文字 `BONUS：HP+10％` 的全角冒号与百分号；单位名称中的 `Ⅱ`、`Ⅲ`、全角 `ｓ`、`（）`（IRON NOKANA MKⅡ、JUPITER KING MKⅡ、THE KEESI Ⅱ / Ⅲ、MH-6ｓ、A.P.C.（SPECIAL FORCE）等，英、西、葡及编号 5、7 的语言共 2–9 个名称，清单 `verification/deck_paging_20261111/names_missing.json`）；韩语文字中的 3 个日文汉字。
- 做法：`FontLayout.font_of` 逐字符选字体——所选字体有字形时用所选字体；没有时依次在 `GLYPH_FALLBACKS`（微软正黑、微软雅黑、MS Gothic、Malgun Gothic、Segoe UI Symbol、Arial 中已安装者）里找有该字形的字体；都没有时仍用所选字体。是否有字形以该字符的栅格与未定义字形（U+FFFF）的栅格比较判定（`has_glyph`，按字体缓存）。回退字体在首次遇到缺字时才载入。行高与基线仍取所选字体，原有文字的宽度与位置不变；原先为方框的字符改用回退字体的字宽。韩语原有的两个指定回退字符照旧。
