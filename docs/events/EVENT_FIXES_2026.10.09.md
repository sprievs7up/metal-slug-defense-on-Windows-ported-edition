# EVENT 浏览页、商店面板与拾取物计数修订（2026-10-09，核心 r31）

## 1. 浏览页第三行误入 Wi-Fi 对战
- 原因：第三行借用主菜单原生“對戰”面板（`app+0x3384`），原生在抬起时受理。宿主吞下按下但放行抬起（两段间隙、按钮外缘、闸门期间），原生据此进入 Wi-Fi 菜单（场景 66/67）。
- 修订（`event_browser.py`）：右侧三行区域及外缘为 `GUARD_RECT`；按下于此且未命中宿主按钮时，整次触点（按下、移动、抬起）不送入原生。

## 2. OPTION 子页面第三行显示分段框
- 原因：分段框替换按绘制 y=364 匹配，OPTION 页第三行同高度。
- 修订：替换表的第三行条目仅在主菜单主页（场景 27，或 28/1）写入；OPTION 等子页面保持原生整框。

## 3. 退出商店后基地“商店”面板消失
- 原因：`close_native_shop` 先清除商店目录头再调用原生基地初始化；面板钩子在目录头为零时写入持续的隐藏标记（0xa0）。
- 修订：先恢复目录头（`prepare_native_shop`），再初始化基地。

## 4. 战斗拾取物计数（圣诞星形、秘宝金币）
- 原因：1.46 `BattlePlayerOperator::createGrahics`（战斗 HUD CPU 合成）内嵌 1.39 版 `event_otakara_ui.obm` 的坐标（星形 9 帧 `0x3af73a`、数字 10 项 `0x3af7ca`、内联 "x" (120,27)），而 1.46 图集已重排（新增合作盾形），裁切得到错位图块，数字亦不可辨。该计数仅在 `BattleGameMaster+0x4828==9`（Survival 初始化）时绘制。
- 修订：`historical_events/assets/event_otakara_ui_hud.obm` 为 1.39 原版图集（1.39/1.40 相同）。钩子 `hud_item_atlas`（`ImageDesc::readFileFromOBM` 入口，返回地址 `0x101dadc2`）在 `H+216` 非零时替换该调用的文件名；`hud_item_frames`（`0x101dade5`）在 `H+220` 非零时以 9 项转换表覆盖栈上星形帧副本。宿主于选择活动时写入：圣诞为 1.39 图集与原生旋转星形；秘宝为 1.39 图集与静态金币（1.37/1.38 原版为静态金币）。其他活动与普通战斗两项为零，行为不变。计数值为 `BattleMain+0x28`（`getGetMSPoint2`）。
