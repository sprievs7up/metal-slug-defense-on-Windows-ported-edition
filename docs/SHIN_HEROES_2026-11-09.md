## 光束接缝（R11）

- 现象：Big 激光的光束段每隔一段宽度出现 1 个屏幕像素的透明列（2560×1440 时间距 72 像素），绝大多数 tick 可见，光束位置使边界未落在屏幕像素中心的 tick 没有接缝。
- 原因：`BulletAction_Eri::draw` 把 16 图像像素宽的光束帧首尾相接；非整数缩放下边界落在屏幕像素中心时，采样点落在矩形之外，取到图集打包间隔的透明像素。原版 Eri 在同条件下有相同接缝；真 Eri 的普通攻击沿用原版帧，用户决定保持原版。
- 修正：`artwork/shin_heroes_20261109/build_shin_heroes.py` 的 `Sheet.add(extrude=True)` 在图集中向外复制一圈边缘像素，矩形数值不变；用于 Big 激光全部帧与 Big 火箭的分块。
- 验证：`verification/shin_heroes_20261109/beam_scan.py` 逐帧统计 ACTION 演示（`MSD_TEST_WINDOW` 指定窗口尺寸）：2560×1440 修改前 33 帧中 28 帧有接缝，修改后 0 帧；1920×1080 修改后 0 帧。真 Fio 的 110 帧演示画面修改前后相同。
